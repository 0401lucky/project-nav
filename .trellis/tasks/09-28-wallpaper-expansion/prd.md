# 新增多样化人物壁纸

## Goal

新增四组外貌和气质不同的成年男性壁纸，每组横竖配对并接入现有壁纸选择器

## Requirements

- 保留现有 4 组壁纸，新增 `w-05` 至 `w-08` 共 4 组，每组横版约 16:9、竖版约 9:16 各一张，总计 8 组 / 16 张。
- 用户纠正后的风格：类似《恋与深空》的精致 3D / 半写实乙游美型，人物均为成年男性。四组以银发冷峻、浅栗发温柔、黑发精英、灰紫发神秘区分，强调漂亮五官、清爽皮肤、细腻眼神和发丝；不采用首轮胡茬、粗犷、成熟写真的方向。
- 横屏人物集中在右侧，左侧约 2/3 保持低细节深色背景供启动器叠加；竖屏单独构图，保持同组人物身份及氛围，上方保留视觉空间。
- 通过用户指定的 `imagegen-third-party` CLI 和 `gpt-image-2.5` 生成。横版完成后，以实际成图作为竖版参考。
- 沿用已有壁纸选择器、横竖自动配对和 AVIF/WebP 两档 + LQIP 管道；单个发布产物不超过 300KB，不新增依赖，不改变当前壁纸选择。

## Acceptance Criteria

- [x] 新增四组为精致 3D / 半写实乙游美型，外貌可明显区分，每组横竖版人物一致，无文字、水印或明显肢体畸形（已逐图检查，最终审美反馈待用户看图）。
- [x] 1440×900 首页能看到人物面部及主体，左侧内容不遮住人物面部；390×844 使用对应竖版，没有横向溢出。
- [x] 设置中可选择全部 8 组主题，原有 4 组及当前选择保留。
- [x] 清单新增 8 张，横竖成对，各档文件存在且 ≤300KB，旧壁纸文件未改动。
- [x] 壁纸相关测试、类型检查和构建通过；完成本地浏览器切换验证。

## 范围与确认

- 用户在听取“四种人物方向、横竖屏配对”的方案后回复“你继续吧”，按该方案执行。
- 用户随后否定首轮人物审美，并明确选择“类似《恋与深空》的精致 3D／半写实感”。首轮 8 张已移至本地忽略目录 `.playwright-mcp/wallpaper-expansion/rejected-round1/`，不接入产品，按新风格重做。
- 本任务只增补素材及其必要清单、数量说明和测试，不重做首页或壁纸管理流程。
- 当前是本地资产与接入工作；生产发布按用户授权范围另行处理。
