# 首页操作易用性

## Goal

常用操作（删除、移动、排序、搜索打开）找得到、做得快，误删可以挽回。沿用父任务约束：
运行时依赖白名单、首屏 JS gzip < 80KB、不引入动画 / 拖拽 / UI 库、backdrop-filter 只用在三类容器。

## 背景与已确认事实

- **删除书签不可挽回**：卡片菜单点「删除」直接调接口，没有确认也不能撤销（`src/App.vue:79-81`）；删除是乐观更新，先从本地数组移除、失败回滚（`src/stores/data.ts:237-248`）；服务端同时删掉图标文件（`server/routes/bookmarks.ts:133-139`）。删除分组已有二次确认（`src/components/panels/GroupForm.vue:88-136`），不在本次范围。
- **提示条不支持操作按钮**：`useToast` 只有 `show / dismiss / error`，每条 3.6s 后消失，整条是一个点了就关的按钮（`src/composables/useToast.ts:15`、`src/components/ui/Toast.vue:10-18`）。
- **拖拽手柄太小**：书签只能拖卡片左侧 11px 宽、悬停才显形的手柄（`BookmarkCard.vue:126-146`、`:238-250`）；分组手柄 12px 宽，同样悬停才显形（`GroupPanel.vue:35-53`、`:117-126`）。
- **卡片本身是 `<a>`**：现在只有手柄 `draggable="true"`，手柄的 `@click.prevent.stop` 防止拖完误打开链接（`BookmarkCard.vue:118-137`）。
- **重排接口要全量 id**：过滤时因此禁用拖拽（`App.vue:117-126`、`GroupPanel.vue:15-19`）。
- **移到别的分组要 4 步**：打开菜单 → 选「移到分组」→ 侧栏下拉框选分组 → 点「移动」（`App.vue:82-86`、`:284-299`）。
- **操作入口**：桌面悬停显示「⋯」或右键卡片打开菜单；窄屏（≤640px）「⋯」常显、手柄隐藏（`BookmarkCard.vue:124`、`:168-181`、`:348-375`）。
- **搜索**：过滤结果在原分组网格里原地筛选显示（`src/composables/useFilter.ts:19-31`）；回车打开显示顺序里的第一条，只有一条都没命中才用搜索引擎（`src/components/home/SearchBox.vue:44-59`）。
- **现有 e2e 依赖当前结构**：`e2e/main.spec.ts:57` 拖 `.card__handle`；`e2e/mobile.spec.ts:67`、`:130-141` 断言手柄与「⋯」的显隐。
- **实施顺序**：父任务原定「先视觉、后交互」。用户 2026-09-26 决定先做交互，视觉留到之后的会话；两者仍先后进行，视觉任务届时在本任务的改动上做。

## Requirements

（以下决策均由用户于 2026-09-26 确认）

- **R1 删除后可撤销**：点「删除」后卡片立即消失，底部提示「已删除「标题」」带「撤销」按钮，约 5 秒。5 秒内只在页面上隐藏、不调删除接口；点「撤销」卡片回到原位置；5 秒到期才真正调用删除接口。期间关掉页面等于没删（接受）。连续删除多条时各自独立计时、各自可撤销。
- **R2 待删除项不能破坏其他操作**：拖拽重排、导入后重新拉取数据、退出登录之前，先把待删除项立即提交删除，保证提交的 id 与服务端一致。真正删除失败时恢复卡片并提示。
- **R3 拖整张卡片 / 整个标题栏**：去掉书签和分组的小手柄。书签按住卡片任意位置可拖；分组按住标题栏空白处可拖，从「添加」「编辑」按钮上按下不会触发拖拽。单击照常打开链接，拖完不会误打开。过滤状态下、窄屏（≤640px）不可拖，与现在一致。接受代价：宽屏下卡片不能再当普通链接拖到地址栏或别的标签页。
- **R4 菜单里直接选分组**：菜单入口不变（悬停「⋯」、右键卡片、窄屏常显「⋯」）。菜单中「移到分组」改为不可点的小标题，下面列出除当前分组以外的所有分组（带分组图标），点一下即移过去，底部提示「已移到「分组名」」；分组多时菜单内部滚动。只有一个分组时不显示这一节。删除侧栏里的「移到分组」面板。
- **R5 搜索结果 ↑↓ 选择**：焦点在搜索框、有匹配结果时，↓ / ↑ 按显示顺序在结果间移动（到头不循环）；当前项在网格里加强调色描边并滚动到可见位置；提示行变成「回车打开「当前项」」。改搜索词后回到第一项。←→ 仍用来移动输入光标。没有匹配时方向键不起作用。
- **R6 主动用搜索引擎搜**：搜索框有内容时，右侧显示「用 {搜索引擎名} 搜」按钮，点击后在新标签页用设置里选的搜索引擎搜当前词；在搜索框里按 Shift+回车效果相同。有匹配时提示行写「回车打开「当前项」 · Shift+回车 用 {搜索引擎名} 搜」。普通回车的行为不变：有匹配打开当前项，无匹配用搜索引擎。输入法组词时的回车仍然忽略。

## Acceptance Criteria

- [ ] 删除一条书签：卡片立即消失并出现带「撤销」的提示；5 秒内点「撤销」，卡片回到原位置，刷新页面后仍在
- [ ] 删除后不撤销：约 5 秒后刷新页面，书签确实已删除
- [ ] 删除后 5 秒内拖动同组另一条书签重排：不报错，刷新后顺序正确，被删的那条也确实已删除
- [ ] 按住卡片中部（不是左边缘）拖到同组第一位、拖到另一个分组，都能生效且刷新后保持；单击卡片仍打开链接
- [ ] 按住分组标题栏空白处能拖动分组排序；点「添加」「编辑」按钮行为不变
- [ ] 过滤状态下、窄屏（≤640px）卡片不可拖；页面上不再有 `.card__handle` / `.panel__handle`
- [ ] 卡片菜单里直接点目标分组，书签移过去并提示「已移到「分组名」」；菜单里不出现当前分组；侧栏里没有「移到分组」面板
- [ ] 搜索命中多条时按 ↓ 两次再回车，打开的是显示顺序里的第三条；当前项有描边、提示行跟着变
- [ ] 有书签命中时按 Shift+回车、或点「用 {搜索引擎名} 搜」，打开的是搜索引擎地址而不是书签
- [ ] `npm run typecheck`、`npm test`、`npm run e2e` 全部通过（e2e 同步改掉对手柄的依赖，并覆盖以上新行为）
- [ ] `vite build` 后首屏 JS gzip < 80KB；没有新增运行时依赖

## Out of Scope

- 首页视觉调整（布局、卡片信息、首字色块、按钮主次）：属于 `09-25-home-visual-refresh`。
- 移动、编辑的撤销；服务端回收站 / 软删除；关掉页面时补提交待删除项。
- 移动端拖拽排序；网格内的键盘焦点导航（除搜索框 ↑↓ 外）。
- 删除分组的交互（已有二次确认，不改）。
