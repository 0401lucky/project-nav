# 新增人物壁纸与分组折叠

## Goal

新增四组横竖配对的乙游风人物壁纸，并让首页分组可以独立折叠，减少不常用书签占用的空间；两项一起发布上线。

## Requirements

- 保留现有 4 组壁纸，新增 `w-05` 至 `w-08` 共 4 组，每组横版约 16:9、竖版约 9:16 各一张，总计 8 组 / 16 张。
- 用户纠正后的风格：类似《恋与深空》的精致 3D / 半写实乙游美型，人物均为成年男性。四组以银发冷峻、浅栗发温柔、黑发精英、灰紫发神秘区分，强调漂亮五官、清爽皮肤、细腻眼神和发丝；不采用首轮胡茬、粗犷、成熟写真的方向。
- 横屏人物集中在右侧，左侧约 2/3 保持低细节深色背景供启动器叠加；竖屏单独构图，保持同组人物身份及氛围，上方保留视觉空间。
- 通过用户指定的 `imagegen-third-party` CLI 和 `gpt-image-2.5` 生成。横版完成后，以实际成图作为竖版参考。
- 沿用已有壁纸选择器、横竖自动配对和 AVIF/WebP 两档 + LQIP 管道；单个发布产物不超过 300KB，不新增依赖，不改变当前壁纸选择。

### 分组折叠

- 每组独立展开/折叠，默认全部展开；收起后只显示分组标题、书签数量和操作入口。桌面与手机都可操作。
- 常显箭头按钮作为折叠入口，点击标题区域也可切换；添加、编辑按钮不触发折叠，标题栏拖拽排序不触发误折叠。
- 用户已确认：使用当前浏览器的 localStorage 按稳定分组 id 记住折叠状态，刷新或重新打开后保留；不新增服务端字段或跨设备同步。
- 有搜索匹配时临时展开匹配分组，清空搜索恢复保存的状态；无匹配时保留原来的折叠状态。搜索临时展开不写回偏好。
- 折叠的分组仍可拖动排序，也可接收拖入的书签；添加/编辑入口保持可用。新建书签成功后展开其所在组，让保存结果可见。
- 本地存储不可用或内容损坏时仍能正常使用折叠，不影响首页启动或服务端数据。

## Acceptance Criteria

- [x] 新增四组为精致 3D / 半写实乙游美型，外貌可明显区分，每组横竖版人物一致，无文字、水印或明显肢体畸形（已逐图检查，最终审美反馈待用户看图）。
- [x] 1440×900 首页能看到人物面部及主体，左侧内容不遮住人物面部；390×844 使用对应竖版，没有横向溢出。
- [x] 设置中可选择全部 8 组主题，原有 4 组及当前选择保留。
- [x] 清单新增 8 张，横竖成对，各档文件存在且 ≤300KB，旧壁纸文件未改动。
- [x] 壁纸相关测试、类型检查和构建通过；完成本地浏览器切换验证。
- [x] 任意分组可独立折叠、展开，数量与标题保留；刷新后保留选择。
- [x] 搜索能展示折叠组中的匹配结果，清空后恢复；无匹配不展开所有分组。
- [x] 折叠按钮支持键盘、`aria-expanded` 与清晰名称；手机可点击，隐藏书签不会被 Tab 聚焦。
- [x] 分组拖拽、拖入折叠组、添加/编辑按钮及新增书签后的展示正常。
- [x] 损坏/不可用 localStorage 不导致页面错误；相关回归测试、全量单测、构建和 E2E 通过。
- [x] 新壁纸与分组折叠一起推送 main 并部署，服务器健康与数据指纹通过；公网浏览器复核受策略限制，详见 verification.md。
