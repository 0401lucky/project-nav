# 重构为个人书签导航站（自部署）

## Goal

把现有"极光导航"（公开项目展示站，Cloudflare Pages + KV）整体重写为**只给一个人用的书签导航站**，部署到自己的服务器。目标排序：性能 > 好看 > 功能多。易用、方便是底线。

## 背景与现状

- 现有代码约 9000 行：Vue 3 + Pinia + 原生 CSS，后端 Cloudflare Pages Functions + KV。
- 堆了大量与"个人书签"无关的功能：存活检测、截图 OCR、AI 工作台、公开投稿审核、多 LLM 服务商后台、嵌入模式、点击计数、公开/私有区分。
- 用户明确要求：全部重构，包括 UI；不再绑 Cloudflare。

## Requirements

### 功能需求

1. **登录**：打开站点先输密码；密码来自环境变量；登录态 HttpOnly Cookie 保持 90 天；连错 5 次锁 10 分钟。
2. **首页**：顶栏（站名、新增、设置）+ 大搜索框 + 按分组排列的书签卡片网格；只发一次 `/api/bootstrap` 请求拿全量数据。
3. **搜索**：输入即时过滤书签（标题、URL、描述、分组名）并高亮；`/` 或 `Cmd+K` 聚焦；有匹配时回车打开第一个；无匹配时回车用配置的搜索引擎搜该词。
4. **分组**：新增、改名、删除（删除时书签可移到其他组或一起删）、拖拽排序；可选一个 emoji 图标。
5. **书签**：新增、编辑、删除、组内拖拽排序、跨组拖拽；点击在新标签页打开。
6. **URL 自动补全**：新增面板贴 URL 后自动抓取标题、描述、图标候选；失败不阻塞保存。
7. **图标本地缓存**：抓到的图标下载到服务器本地，转 64px WebP；抓不到时用标题首字 + 域名哈希色块兜底。
8. **Bookmarklet**：设置里提供可拖到书签栏的按钮；在任意网页点击后跳到本站并预填当前页 URL 与标题；通过长随机令牌校验。
9. **导入**：浏览器导出的书签 HTML（文件夹 → 分组）；旧站 `/api/projects` 导出的 JSON（category → 分组、name → 标题）。
10. **壁纸**：内置 4 张 AI 生成壁纸（横竖各一版）；设置里九宫格切换；支持上传自定义图片（≤10MB），服务端转 WebP 多档尺寸。
11. **设置**：壁纸、网页搜索引擎（Google / Bing / DuckDuckGo / 自定义模板）、强调色、bookmarklet、导入入口。

### 非功能需求

- **性能**：首屏 JS 压缩后 < 80KB；壁纸单张 ≤ 300KB（AVIF/WebP，两档尺寸 + 低清占位）；Lighthouse 性能 ≥ 95；backdrop-filter 只用在分组面板 / 弹出面板 / 卡片三类容器；不引入动画库、拖拽库、路由库、UI 库。
- **部署**：一个 Dockerfile + docker-compose；只挂载一个 `./data` 目录（SQLite、图标缓存、上传壁纸）；环境变量仅 `PASSWORD`、`SESSION_SECRET`，缺失即启动失败。
- **依赖最少**：运行时依赖控制在 Hono、Vue、Pinia、sharp（图片转码）范围内。
- **语言**：代码注释、文档、提交信息使用简体中文。

## 不在范围内

- 多用户、公开访问、分享链接
- 存活检测、点击统计、OCR、AI 工作台、投稿
- 亮色主题（壁纸风格决定深色底）
- 浏览器扩展
- 移动端拖拽排序（移动端只读 + 基础增删改）

## Acceptance Criteria

- [ ] 未登录访问任何页面或 API 均被拒绝；输入正确密码后 90 天内免登录；连错 5 次锁 10 分钟
- [ ] 首页加载只发一次数据请求，展示全部分组与书签，卡片点击新标签打开
- [ ] 搜索框：输入过滤 + 高亮；`/` 与 `Cmd+K` 聚焦；有匹配回车打开首个，无匹配回车跳搜索引擎
- [ ] 分组可新增、改名、删除、拖拽排序；书签可新增、编辑、删除、组内与跨组拖拽；刷新后顺序保持
- [ ] 新增面板贴 URL 后 3 秒内自动填入标题/描述/图标候选；抓取失败仍可手填保存
- [ ] 图标全部来自本站本地路径；无图标的书签显示首字色块
- [ ] Bookmarklet 从任意网页点击后能打开本站并预填 URL 与标题
- [ ] 导入 Chrome 导出的书签 HTML 后，文件夹变分组，书签进对应分组；导入旧站 JSON 后 category 变分组
- [ ] 内置 4 张壁纸可切换；上传 10MB 内图片后可选用；壁纸与遮罩下文字始终可读
- [ ] `docker compose up` 后可用；重启容器数据不丢；备份 `./data` 目录即可恢复
- [ ] `vite build` 后首屏 JS gzip < 80KB；Lighthouse 性能 ≥ 95
- [ ] 后端 `node:test` 测试覆盖鉴权、CRUD、排序、导入解析、URL 元信息解析并全部通过
- [ ] Playwright 主路径（登录 → 贴 URL 新增 → 拖拽 → 搜索跳转 → 切壁纸）通过
- [ ] 旧代码（`functions/`、`wrangler.toml`、旧 `src/`）全部删除，README 重写为新部署说明
